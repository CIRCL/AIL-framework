What is link depth?

Link depth sets how many steps a crawl can take by following links from the starting page.

Depth 0
Capture the starting page only.
Depth 1
Also follow links on the starting page.
Depth 2
Follow links one level farther from those pages.

What is a HAR?

A HAR (HTTP Archive) is a JSON file that records the requests and responses a browser exchanges while loading a page. It shows which resources loaded, which requests failed, and how long they took.
