Graph help and keyboard shortcuts

Click a node to select it, or a legend type to select matching objects. Hold Ctrl, Cmd or Shift to add types to your selection. Double-click an object to open it.

Groups contain at least 10 objects of the same type with identical visible neighbours. Double-click a group to unpack it immediately; use its close button to pack it again. Toggle Shared correlations in Simplify to show objects separately.

Press H while hovering an object or group to hide it. Hiding keeps the loaded objects in memory and does not load replacements. Use Undo last hide or Restore all hidden to show them again. The orange starting object is protected from Hide. Use Pivotick’s Fit and center control to fit the graph.
